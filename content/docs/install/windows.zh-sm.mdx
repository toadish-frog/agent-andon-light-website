Windows 上用的是一键安装程序，而不是命令行安装。下载下来运行就行，不需要管理员权限。

## 1. 下载并运行安装程序

从项目的 [GitHub Releases 页面](https://github.com/toadish-frog/agent-andon-light/releases)下载 `andon-light-setup.exe` 并运行。它只针对你的用户账号安装（不会弹出管理员权限提示），并且会自动加入 PATH。

## 2. 关于安全警告

安装程序和工具本身都没有数字签名，所以不管第一次运行哪一个，Windows 都会弹出"Windows 已保护你的电脑"的警告，某些杀毒软件也可能会报警。这是这类小型未签名工具打包方式的副作用，恰好和某些恶意软件的行为有点像，并不代表任何东西坏了。

**要继续运行：** 点"更多信息"，然后点"仍要运行"。

真正能解决这个警告的办法（买一个代码签名证书）一年大概要 70 到 400 美元。而且就算买了新证书，也需要时间才能在 Windows 那边积累起信任度。对于一个只直接分发给少数人的业余项目来说，现在还不值得为此花这笔钱。

## 3. 检查是否成功

打开一个**新的**终端窗口（安装之前就开着的终端感知不到更新后的 PATH），运行：

```bash
andon-light doctor
```

确认工具能找到你的设备。

## 4. 接上你用的 agent

安装程序完成页面上有两个各自独立的复选框，一个对应 Claude Code，一个对应 Codex CLI：勾选你用到的那个（或两个都勾）。勾选后会自动为对应的 agent 运行 `andon-light install-hooks`，走的是和 [Claude Code Hook 集成](/docs/software/claude-code-hooks)、[Codex CLI Hook 集成](/docs/software/codex-cli-hooks)里说的一样的流程：先展示要改的内容，再等你确认。以后你也可以随时自己在终端里运行：

```bash
andon-light install-hooks                 # Claude Code
andon-light install-hooks --agent codex   # Codex CLI
```

如果你勾选了 Codex CLI，还有一步安装程序代替不了：打开 Codex CLI，运行一次 `/hooks`，信任新的 hook 文件。原因，以及如果你只用 ChatGPT 桌面应用的 Codex 标签页需要多做的那一步，参见 [Codex CLI Hook 集成](/docs/software/codex-cli-hooks#运行前先信任它)。

## 遇到问题？

参见故障排查页面的 [Windows 专属说明](/docs/hardware/troubleshooting#windows-专属说明)，里面讲了安装后的 PATH 问题，以及从旧版本升级时怎么清理残留的 PATH 记录。
