Linuxでは、専用のインストーラーをビルドする必要はありません。コマンドラインツールはそのままPyPIに公開されているので、インストールはコマンド1つで済みます。このページは、ターミナルの操作にある程度慣れていることを前提にしています。

## 1. インストールする

```txt
sudo apt install -y pipx   # pipxをまだ持っていない場合のみ
pipx install andon-light
```

プロジェクトのリポジトリをクローンする必要はありません。公開済みのパッケージを直接インストールします。

## 2. うまくいったか確認する

```txt
andon-light doctor
```

ツールが実際にデバイスを見つけられるかを確認します。権限エラーが表示された場合は、ユーザーアカウントを `dialout` グループに追加する必要があります。具体的な手順はトラブルシューティングページの[Linux特有の注意点](/docs/hardware/troubleshooting#linux特有の注意点)を参照してください。

## 3. 使っているエージェントと接続する

```txt
andon-light install-hooks                 # Claude Code
andon-light install-hooks --agent codex   # Codex CLI
```

どちらも、追加しようとしている内容を、変更前にそのまま表示し、確認を求めます。適用範囲もグローバルか、プロジェクト単位かを選べます。実際に何が設定され、なぜそういう作りになっているのかは[Claude Code フック連携](/docs/software/claude-code-hooks)または[Codex CLI フック連携](/docs/software/codex-cli-hooks)を参照してください。Codex CLIを使う場合は、フックが実際に動き出す前にもう一段階必要な手順があります——[実行前に信頼を与える](/docs/software/codex-cli-hooks#実行前に信頼を与える)を参照してください。
