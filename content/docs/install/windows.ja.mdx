Windowsでは、コマンドライン操作の代わりにワンクリックのインストーラーが用意されています。ダウンロードして実行するだけの小さなプログラムで、管理者権限は必要ありません。

## 1. インストーラーをダウンロードして実行する

プロジェクトの[GitHubリリースページ](https://github.com/toadish-frog/agent-andon-light/releases)から `andon-light-setup.exe` を取得し、実行してください。ユーザーアカウント単位でインストールされ（管理者権限のプロンプトは出ません）、PATHにも自動的に追加されます。

## 2. セキュリティ警告について

インストーラーもツール本体も、デジタル署名がされていません。そのため、どちらを初めて実行してもWindowsが「Windows によって PC が保護されました」という警告を表示し、一部のセキュリティソフトが反応することもあります。これは、このような小規模で未署名のツールがパッケージ化される際によく起こる副作用で、一部のマルウェアの挙動と似て見えてしまうことが原因です。何かが壊れているわけではありません。

**そのまま続行するには：** 「詳細情報」をクリックし、続けて「実行」をクリックします。

この警告への本当の対策（有料のコード署名証明書を取得すること）には、年間おおよそ70〜400ドルほどかかります。しかも、新しく取得した証明書であっても、Windows側の信頼を積み上げるまでには時間がかかります。ごく少人数に直接配布するだけの趣味のプロジェクトとしては、今のところそこまでする価値はないと考えています。

## 3. うまくいったか確認する

**新しい**ターミナルウィンドウを開き（インストール前から開いていたターミナルは、更新後のPATHを認識しません）、次を実行します。

```txt
andon-light doctor
```

ツールがデバイスを見つけられるか確認できます。

## 4. Claude Codeと接続する

インストーラーの完了画面にあるチェックボックスをオンにすると、[Claude Code フック連携](/docs/software/claude-code-hooks)で説明している「変更内容を表示してから確認を求める」流れで、`andon-light install-hooks` を自動的に実行してくれます。後からでも、ターミナルで次を実行すればいつでも同じことができます。

```txt
andon-light install-hooks
```

## うまくいかない場合

トラブルシューティングページの[Windows特有の注意点](/docs/hardware/troubleshooting#windows特有の注意点)を参照してください。インストール後のPATHの問題や、古いバージョンからアップグレードする際に残ってしまうPATHの後始末について説明しています。
