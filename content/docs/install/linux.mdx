There's no separate installer to build here. On Linux, the command-line tool is published straight to PyPI, so installing it is a single command. This page assumes you're reasonably comfortable in a terminal.

## 1. Install

```txt
sudo apt install -y pipx   # skip this if you already have pipx
pipx install andon-light
```

No need to clone the project's repository. This pulls the published package directly.

## 2. Check it worked

```txt
andon-light doctor
```

This confirms the tool can actually find your device. If it reports a permission error instead, your user account needs to be added to the `dialout` group. See the [Linux-specific section](/docs/hardware/troubleshooting#linux-specific-notes) of the troubleshooting page for exactly how.

## 3. Connect it to your agent

```txt
andon-light install-hooks                 # Claude Code
andon-light install-hooks --agent codex   # Codex CLI
```

Either way, this shows you exactly what it's about to add before making any changes, asks you to confirm, and lets you choose whether to apply it globally or to a single project. See [Claude Code Hooks](/docs/software/claude-code-hooks) or [Codex CLI Hooks](/docs/software/codex-cli-hooks) for what this actually sets up and why it's built the way it is. If you use Codex CLI, there's one more step it requires before hooks actually run. See [Trust it before it runs](/docs/software/codex-cli-hooks#trust-it-before-it-runs).
