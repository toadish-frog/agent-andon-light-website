このリストにある部品は、どれも入手しやすい普通の部品ばかりです：特殊なものや輸出規制のかかるものは一切ありません。小さな開発ボードと、アドレサブルLEDと、いくつかの受動部品だけです。

## 基板の製造を依頼する場合

これが現在の製作方法です。基板製造サービスがマイコン以外のすべての部品を実装・ハンダ付けしてくれます。マイコンだけは自分でハンダ付けします（[組み立てガイド](/docs/hardware/build-guide)を参照）。

| 部品 | 説明 | 数量 |
| --- | --- | --- |
| Waveshare RP2040-Zero | マイコンボード：ファームウェアを動かす本体です | 1 |
| WS2812B-2020 | アドレサブルRGB LED | 10 |
| 470 µF 電解コンデンサ | LEDへの電源を安定させます | 1 |
| 100 nF セラミックコンデンサ | LED1個につき1個、それぞれの動作を安定させます | 10 |
| 330 Ω 抵抗 | データラインに入れて、信号関連のトラブルを防ぎます | 1 |

**筐体：** 3Dプリントのケース（ベースとフタ）で、電子部品を隠しつつ光を通します。

正確な部品番号やメーカー、データシートといった詳しいソースは、プロジェクトのGitHub上のハードウェアフォルダにあるKiCadの生成ファイルにまとまっています。この表とそちらの内容が食い違う場合は、そちらが正となります。

## ブレッドボードで試作する場合

完成済み基板を使わずに試作する場合の部品です。

| 部品 | 数量 | 備考 |
| --- | --- | --- |
| Waveshare RP2040-Zero | 1 | |
| LEDテープ基板（WS2812互換、10個） | 1 | |
| ハーフサイズのブレッドボード | 1 | |
| ジャンパーワイヤー（オス-オス、オス-メス） | 1セット | |
| LEDテープのヘッダに合う3ピンコネクタ | 1 | お手元のテープのコネクタ形状に合わせてください |
| USB-C to USB-Aケーブル | 1 | データ通信対応のケーブルであることを確認してください。安価なケーブルには充電専用のものが多くあります |
| 74HCT125 レベルシフター | 1（任意） | データラインの信号が乱れる場合のみ必要です |
| 330–470 Ω 抵抗 | 1（任意、推奨） | データラインの、テープ側の端近くに入れます |
| 電解コンデンサ、100–1000 µF、6.3V以上 | 1（任意、推奨） | 電源とグラウンドの間、テープ側の端近くに入れます。極性（プラスとマイナス）にご注意ください。向きを間違えると入りません。 |

ここではRP2040-Zeroにピンヘッダをハンダ付けする以外、ハンダ付けは不要です。他はすべて差し込むだけで組み立てられます。

## 知っておくと良いこと

- 製造サービスに部品の実装を依頼する場合は、注文を確定する前に、リストの部品がそのサービスの在庫にあるかどうかを確認しておきましょう。手作業でハンダ付けする場合はこの制約はありません。
- LED基板を自分で設計し直す場合は、予備を1枚多く注文しておくのがおすすめです：LEDの故障や配線ミスに対する安価な保険になります。
- この製品の初期バージョンでは、LEDテープの代わりに3個の独立した色のLEDを使っていました。参考として残していますが、現行の構成には含まれていません。
