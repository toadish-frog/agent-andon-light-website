清单上的每一样都是很常见、容易买到的零件——没有任何出口管制或者稀奇古怪的东西。就是一块小小的开发板，一些可寻址 LED，加上几个无源元件。

## 如果找厂家代工电路板

这是目前实际使用的做法。代工厂会帮你把除了单片机以外的所有元件都贴装好、焊好——单片机这一个部件需要自己焊（参见[组装指南](/docs/hardware/build-guide)）。

| 部件 | 是什么 | 数量 |
| --- | --- | --- |
| Waveshare RP2040-Zero | 单片机板——负责运行固件 | 1 |
| WS2812B-2020 | 可寻址 RGB LED | 10 |
| 470 µF 电解电容 | 让供给 LED 的电源更平稳 | 1 |
| 100 nF 陶瓷电容 | 每颗 LED 配一个，让每颗都工作得更稳定 | 10 |
| 330 Ω 电阻 | 接在数据线上，防止信号出问题 | 1 |

**外壳：** 3D 打印的外壳（底座加盖子），能透光同时把电子元件藏起来。

更详细的采购信息——具体型号、厂商、数据手册——都在项目 GitHub 上硬件文件夹里 KiCad 生成的文件中。如果这张表和那些文件有出入，以那边为准。

## 如果在用面包板试做

不用代工电路板，自己动手试做时需要的东西：

| 部件 | 数量 | 备注 |
| --- | --- | --- |
| Waveshare RP2040-Zero | 1 | |
| LED 灯带板（WS2812 兼容，10 颗） | 1 | |
| 半尺寸面包板 | 1 | |
| 跳线（公对公、公对母） | 1 套 | |
| 匹配 LED 灯带接口的 3 针连接器 | 1 | 要和你手上灯带的接口类型匹配 |
| USB-C 转 USB-A 数据线 | 1 | 确保是能传数据的线，不是只能充电的——很多便宜的线只能充电 |
| 74HCT125 电平转换器 | 1（可选） | 只有遇到数据线信号问题时才需要 |
| 330–470 Ω 电阻 | 1（可选，建议加） | 接在数据线上，靠近灯带那一端 |
| 电解电容，100–1000 µF，6.3V 及以上 | 1（可选，建议加） | 接在电源和地之间，靠近灯带那一端。注意极性，装反了会有问题。 |

除了给 RP2040-Zero 焊排针，这条路线不需要任何焊接——其余部分都是直接插上就行。

## 几点提醒

- 如果找代工厂贴片，下单前先确认清单上的元件在那家厂商自己的库存里有——手工焊接没有这个限制。
- 如果你打算自己重新设计 LED 板，多订一片备用挺划算的——万一有颗 LED 坏了或者接反了，能省不少事。
- 早期版本用的是 3 颗独立的彩色 LED，而不是灯带。留作参考，但不是现在这版的组成部分。
