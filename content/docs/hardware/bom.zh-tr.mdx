清單上的每一樣都是很常見、容易買到的零件：沒有任何出口管制或稀奇古怪的東西。就是一塊小小的開發板，一些可定址 LED，加上幾個被動元件。

## 如果找廠商代工電路板

這是目前實際使用的做法。代工廠會幫你把除了單晶片以外的所有零件都貼裝好、焊好。單晶片這一個零件需要自己焊（參見[組裝指南](/docs/hardware/build-guide)）。

| 零件 | 是什麼 | 數量 |
| --- | --- | --- |
| Waveshare RP2040-Zero | 單晶片板：負責執行韌體 | 1 |
| WS2812B-2020 | 可定址 RGB LED | 10 |
| 470 µF 電解電容 | 讓供給 LED 的電源更平穩 | 1 |
| 100 nF 陶瓷電容 | 每顆 LED 配一個，讓每一顆都運作得更穩定 | 10 |
| 330 Ω 電阻 | 接在資料線上，防止訊號出問題 | 1 |

**外殼：** 3D 列印的外殼（底座加上蓋），能透光同時把電子零件藏起來。

更詳細的採購資訊（確切型號、廠商、資料手冊）都在專案 GitHub 上硬體資料夾裡 KiCad 產生的檔案中。如果這張表和那些檔案有出入，以那邊為準。

## 如果在用麵包板試做

不用代工電路板、自己動手試做時需要的東西：

| 零件 | 數量 | 備註 |
| --- | --- | --- |
| Waveshare RP2040-Zero | 1 | |
| LED 燈條板（WS2812 相容，10 顆） | 1 | |
| 半尺寸麵包板 | 1 | |
| 跳線（公對公、公對母） | 1 組 | |
| 匹配 LED 燈條接頭的 3 針連接器 | 1 | 要和你手上燈條的接頭類型相符 |
| USB-C 轉 USB-A 傳輸線 | 1 | 確保是能傳資料的線，不是只能充電的。很多便宜的線只能充電 |
| 74HCT125 電位轉換器 | 1（可選） | 只有遇到資料線訊號問題時才需要 |
| 330–470 Ω 電阻 | 1（可選，建議加） | 接在資料線上，靠近燈條那一端 |
| 電解電容，100–1000 µF，6.3V 以上 | 1（可選，建議加） | 接在電源和地線之間，靠近燈條那一端。注意極性，裝反了會有問題。 |

除了給 RP2040-Zero 焊排針，這條路線不需要任何焊接。其餘部分都是直接插上就好。

## 幾點提醒

- 如果找代工廠貼片，下單前先確認清單上的零件在那家廠商自己的庫存裡有。手工焊接沒有這個限制。
- 如果你打算自己重新設計 LED 板，多訂一片備用挺划算的：萬一有顆 LED 壞了或接反了，能省不少事。
- 早期版本用的是 3 顆獨立的彩色 LED，而不是燈條。留作參考，但不是現在這版的組成部分。
