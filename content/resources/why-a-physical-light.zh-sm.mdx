---
title: "为什么要做一盏实体的灯"
description: "编码 Agent 的状态其实已经显示在屏幕上了。为什么这样还不够。"
date: "2026-08-07"
---

Claude Code 其实已经会告诉你它在做什么——有个小图标在转，状态栏也一直显示着，全都在终端里。那为什么还要为一些屏幕上已经有的信息，专门做一盏实体的灯？

因为"已经在屏幕上"，还是意味着你得去看那块屏幕。真正高效地和编码 Agent 配合，往往意味着不用一直盯着它——去写点别的东西，去倒杯咖啡，实际上离开一会儿，让它自己把任务推进下去。可每次这样做，回来都得靠打开某个窗口，回答同一个问题：它是还在工作，还是卡在等我处理？

一盏灯，隔着房间就能回答这个问题。绿色代表在工作，黄色代表专门在等你，红色代表空闲。你不需要集中注意力去看，不需要记得它开在哪个窗口，甚至不需要坐在电脑前——瞄一眼就够了。

而且说实话，这本身也挺好玩的。这个项目一开始就是当作业余爱好来做的，不是产品——没有路线图，没有商业计划，唯一的野心就是做点让人会心一笑的小东西。如果你也觉得自己的桌上放一盏编码 Agent 专用的实体状态灯挺有意思，那么自己动手做一台需要的一切，都在[文档](/docs)里。
