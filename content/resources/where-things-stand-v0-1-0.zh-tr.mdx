沒有路線圖，也沒有發表會——只是單純說說專案現在實際走到哪一步了。

**已經做好並測試過：** 5 台，全部手工焊接，用現在這版韌體和主機端 CLI 完整跑過一遍。客製 PCB、3D 列印外殼、通訊協定、Claude Code 的 hook 整合——這些都經過真實使用的檢驗，不只是在桌上測過而已。

**平台支援：** Linux 一行 `pipx install` 指令就能裝好。Windows 有一鍵安裝程式（未簽章，所以需要點掉一個安全性警告——原因見 [Windows 安裝指南](/docs/install/windows)，這是預期之內的）。macOS 還不支援——不是說跑不起來，只是還沒在上面測試過。

**授權條款：** 從頭到尾都是 MIT——韌體、硬體設計檔案、主機端 CLI，以及自動安裝的 hook 設定，全都包含在內。不管你是想自己做一台，還是想改改它的行為，需要的東西都在[原始碼](https://github.com/toadish-frog/agent-andon-light)裡。

**這不是什麼：** 不是商用產品。沒有商店，沒有定價，也沒有路線圖承諾。它是一個興趣專案，只是剛好做到了真正能用的程度，也夠開放，任何人都能照著做一台出來。

如果你自己動手做了一台，歡迎告訴我們——這個 Resources 板塊存在的意義，正是為了放這樣的內容。
