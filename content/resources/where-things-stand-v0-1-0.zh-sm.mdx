没有路线图，也没有发布仪式。只是简单说说项目现在实际到了哪一步。

**已经做好并测试过：** 全部手工焊接，用现在这版固件和主机端 CLI 完整跑通过。定制 PCB、3D 打印外壳、通信协议、Claude Code 的 hook 集成：这些都经过了真实使用的检验，不只是台面上测过而已。

**平台支持：** Linux 一行 `pipx install` 命令就能装好。Windows 有一键安装程序（未签名，所以需要点掉一个安全警告；原因见 [Windows 安装指南](/docs/install/windows)，这是预期之内的）。macOS 还不支持。不是说跑不起来，只是还没在上面测试过。

**许可协议：** 从头到尾都是 MIT：固件、硬件设计文件、主机端 CLI，以及自动安装的 hook 配置，全都包含在内。不管你是想自己做一台，还是想改改它的行为，需要的东西都在[源码](https://github.com/toadish-frog/agent-andon-light)里。

**这不是什么：** 不是商用产品。没有商店，没有定价，也没有路线图承诺。它是一个业余项目，只是刚好做到了真正能用的程度，也足够开放，任何人都能照着做一台出来。

如果你自己动手做了一台，欢迎告诉我们。这个 Resources 板块存在的意义，正是为了放这样的内容。
