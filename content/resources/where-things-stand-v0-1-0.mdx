No roadmap, no launch event — just a quick note on where the project actually is right now.

**Built and tested:** five units, soldered by hand, running the current firmware and host CLI end to end. The custom PCB, the 3D-printed enclosure, the wire protocol, the Claude Code hook integration — all of it's been through real use, not just a bench test.

**Platform support:** Linux is a one-line `pipx install`. Windows has a one-click installer (unsigned, so you'll need to click through a security warning — see the [Windows install guide](/docs/install/windows) for why that's expected). macOS isn't supported yet — it's not that it won't work, it just hasn't been tested there.

**License:** MIT, all the way through — firmware, hardware design files, host CLI, and the hook config it installs. If you want to build your own or change how it works, everything you need is in the [source](https://github.com/toadish-frog/agent-andon-light).

**What this isn't:** a commercial product. There's no store, no pricing, no roadmap promises. It's a hobby project that happens to be finished enough to be genuinely useful, and open enough for anyone else to build one too.

If you build one yourself, we'd like to hear about it — that's exactly the kind of thing this Resources section is for.
