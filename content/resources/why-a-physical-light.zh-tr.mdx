Claude Code 其實已經會告訴你它在做什麼——有個小圖示在轉，狀態列也一直顯示著，全都在終端機裡。那為什麼還要為一些螢幕上已經有的資訊，特地做一盞實體的燈？

因為「已經在螢幕上」，還是代表你得去看那個螢幕。真正順暢地和 Coding Agent 配合，往往代表不用一直盯著它——去寫點別的東西，去泡杯咖啡，實際上離開一下，讓它自己把工作推進下去。可每次這樣做，回來都得靠打開某個視窗，回答同一個問題：它是還在工作，還是卡在等我處理？

一盞燈，隔著房間就能回答這個問題。綠色代表在工作，黃色代表專門在等你，紅色代表閒置。你不需要集中注意力去看，不需要記得它開在哪個視窗，甚至不需要坐在電腦前——瞄一眼就夠了。

而且說實話，這本身也挺好玩的。這個專案一開始就是當作興趣在做的，不是產品——沒有路線圖，沒有商業計畫，唯一的野心就是做點會讓人會心一笑的小東西。如果你也覺得自己的桌上放一盞 Coding Agent 專用的實體狀態燈挺有意思，那麼自己動手做一台需要的一切，都在[文件](/docs)裡。
